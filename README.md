## How to use

These are instruction files, not software installers. Add the skill folders to the skills directory supported by your Gemini experience or agent client, then enable/import them using that product's current Skills workflow. Keep each skill folder together with its `SKILL.md`.

## Working principles

- Prioritize production-ready, portfolio-worthy results over generic advice.
- Give practical steps, checkpoints, and verifiable quality criteria.
- Distinguish confirmed software features from version-dependent or uncertain details.
- Do not invent menu paths, settings, benchmark results, or asset capabilities.
- Ask for the software version, target platform, and constraints when they materially affect the answer.
- Encourage original work and clearly label the use of marketplace or third-party assets.
- Tailor performance advice to the user's stated hardware; never assume unknown CPU or storage details.

## Suggested workflow

For a new environment project: use Environment Art & Level Design for planning, 3D Modelling Expert for original assets, Lighting & Rendering Specialist for look development, Unreal Engine Expert for implementation, Game Development Studio Assistant for production tracking, and 3D Portfolio & Career Mentor for presentation.

## Hardware context

When the user confirms the same workstation is still in use, consider the stated NVIDIA RTX 3060 and 32 GB RAM. CPU model and exact VRAM configuration are not assumed; ask before giving hardware-specific estimates.
